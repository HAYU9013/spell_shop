# 咒語店 (Spell Shop) — 遊戲企劃文件

---

## 1. 遊戲概述

### 1.1 核心定位

| 項目 | 內容 |
|------|------|
| 類型 | 策略 / 卡牌 / Roguelite |
| 參考作品 | Slay the Spire、Potion Craft |
| 核心樂趣 | 資源管理、組合運算、風險評估 |
| 目標玩家 | 喜歡思考深度與組合系統的策略玩家 |

### 1.2 一句話說明

> 玩家扮演咒語店老闆，透過組合符文與卷軸滿足顧客需求，同時在環境變數的壓力下維持遺物的平衡，一關接一關地接待顧客隊列，以業績為代價持續擴充手中的牌池。

---

## 2. 世界觀與故事背景

玩家繼承了一間神秘的咒語商店。每天都有各式各樣的顧客帶著奇特的需求上門：旅人需要溫暖、農夫需要陽光、病人需要乾燥的空氣。店內擺放著古老的遺物，它們對環境極為敏感，若不加以照料將帶來災禍。

玩家的目標是清空每一關的顧客隊列，在遺物的壓力與顧客的需求之間找到微妙的平衡，並在關卡間透過批發商強化自己的牌池，向更深的關卡邁進。

---

## 3. 核心系統

### 3.1 環境系統

環境是整個遊戲的「共享狀態」，所有符文、卷軸、遺物的效果都作用於環境數值上。**環境數值在回合之間持續保留，不會重置。**

#### 環境變數

| 變數 | 說明 | 初始值 | 數值範圍 |
|------|------|--------|---------|
| 亮度 (Brightness) | 光線強度 | 5 | 0 ~ 20 |
| 水分 (Moisture) | 環境溼度 | 5 | 0 ~ 20 |
| 溫度 (Temperature) | 環境溫度 | 5 | 0 ~ 20 |
| 業績 (Score) | 累積分數，降至 0 則 Game Over | 30 | 0 ~ ∞ |

- 業績是玩家的生命線：顧客滿意獲得業績，顧客不滿意（憤怒離開）扣除業績
- 業績同時作為批發商的購買貨幣

#### 極端事件

數值觸碰邊界（0 或 20）時，**立即觸發一次性的極端事件**，該回合結算後即解除（不持續）。

| 事件 | 觸發條件 | 效果（單次） |
|------|---------|-------------|
| 黑暗降臨 | 亮度 = 0 | 亮度強制設為 0，所有遺物不滿意計數 +1 |
| 大洪水 | 水分 = 20 | 水分強制設為 20，水分 +5（可再次觸發） |
| 高溫爆發 | 溫度 = 20 | 溫度強制設為 20，業績 -10 |
| 極寒侵襲 | 溫度 = 0 | 溫度強制設為 0，業績 -10 |

### 3.2 符文系統

符文是最基本的效果單位，代表單一的環境修改操作。

#### 符文結構

```
符文 {
  名稱
  類型（循環型 / 消耗型）
  效果列表（例：水分 +2、亮度 -1）
  特殊效果（可選，例：移除一個遺物）
  稀有度（普通 / 稀有 / 傳說）
  標籤（水系 / 火系 / 光系 / 暗系 / 風系 / 中性）
}
```

#### 符文類型

| 類型 | 說明 |
|------|------|
| **循環型** | 使用後進入棄牌堆，牌庫抽完後洗牌重來 |
| **消耗型** | 使用後永久從牌庫移除 |

消耗型符文通常效果更強，是一次性的「王牌」。

#### 稀有度

稀有度除了代表效果強度外，也決定出現在獎勵池的機率。玩家無法主動選擇稀有度。

| 稀有度 | 獎勵池機率 | 特性 |
|--------|-----------|------|
| 普通 | 高 | 效果穩定，適合牌庫基底 |
| 稀有 | 中 | 效果較強，通常帶有副作用 |
| 傳說 | 低 | 效果強大但侷限性高，常為消耗型 |

#### 標籤系統

標籤決定符文的屬性，並在以下三個層面產生作用：

| 層面 | 說明 | 範例 |
|------|------|------|
| **卷軸限制** | 特定卷軸只接受特定標籤的符文 | 水系卷軸只能放水系符文 |
| **顧客偏好** | 部分顧客需求要求使用特定標籤的符文 | 「希望用火焰的方式取暖」→ 卷軸內至少 1 張火系符文 |
| **遺物觸發** | 部分遺物對特定標籤的使用有反應 | 「日晷」每當使用光系符文，額外 +2 業績 |
| **標籤連鎖** | 同一卷軸中放入 2 張以上相同標籤，觸發連鎖加成 | 2 張水系符文 → 水分效果總計 +1；3 張 → +2 |

**標籤一覽**

| 標籤 | 主要影響 | 代表符文 |
|------|---------|---------|
| 水系 | 水分↑、溫度↓ | 水珠、寒冰 |
| 火系 | 溫度↑、水分↓ | 小燭、熔岩珠 |
| 光系 | 亮度↑ | 螢石、太陽核 |
| 暗系 | 亮度↓ | 黑霧、陰影核 |
| 風系 | 多項數值小幅調整 | 微風、颶風珠 |
| 中性 | 複合效果，無標籤加成 | 蒸氣、平衡石 |

#### 範例符文

| 符文名稱 | 類型 | 效果 | 稀有度 | 標籤 |
|---------|------|------|-------|------|
| 水珠 | 循環 | 水分 +2 | 普通 | 水系 |
| 小燭 | 循環 | 亮度 +1、溫度 +1 | 普通 | 火系、光系 |
| 寒冰 | 循環 | 溫度 -3、水分 +1 | 稀有 | 水系 |
| 太陽核 | 消耗 | 亮度 +5、溫度 +3、水分 -2 | 傳說 | 火系、光系 |
| 黑霧 | 循環 | 亮度 -2、水分 +1 | 普通 | 暗系 |
| 蒸氣 | 循環 | 溫度 -1、水分 -1、亮度 +1 | 普通 | 中性 |
| 驅逐石 | 消耗 | 移除一個遺物（玩家選擇） | 稀有 | 中性 |

### 3.3 卷軸系統

卷軸是符文的容器與放大器，決定符文效果如何被計算。**卷軸為消耗品，使用後移除。**

#### 卷軸結構

```
卷軸 {
  名稱
  符文槽數（必須放滿才能送出）
  修飾規則（如：所有效果 ×2）
  標籤限制（如：只能放水系符文）
  稀有度
}
```

#### 每回合行動規則

- **一個回合只能送出一個卷軸**
- 送出後環境立即更新，顧客進行一次需求判定
- 若顧客尚未滿足，下一回合可繼續送出新卷軸繼續服務同一位顧客
- 即：**服務一位顧客可橫跨多個回合，使用多個卷軸**

#### 範例卷軸

| 卷軸名稱 | 槽數 | 修飾規則 | 標籤限制 |
|---------|------|---------|---------|
| 基礎卷軸 | 2 | 效果直接疊加 | 無 |
| 放大卷軸 | 3 | 所有效果 ×2 | 無 |
| 純化卷軸 | 2 | 只計算正值效果 | 無 |
| 水系卷軸 | 3 | 水系效果 ×3 | 僅限水系符文 |
| 平衡卷軸 | 4 | 所有效果取平均後套用（保留小數） | 無 |
| 逆轉卷軸 | 2 | 所有效果正負反轉（仍可觸發極端事件） | 無 |

> **設計要點**：必須「放滿」才能送出，強迫玩家做出取捨，不能只放有利的符文。

#### 卷軸補充來源

1. **顧客獎勵**：完成顧客需求後，隨機獲得卷軸
2. **批發商**：每關通關後，可消耗業績向批發商購買卷軸（詳見第 6 節）

---

### 3.4 顧客系統

顧客是每關的主要挑戰。**同一時間只有一位顧客**，舊顧客離開後（滿足或憤怒）新顧客立即登場。顧客隊列清空代表該關通關。

#### 顧客結構

```
顧客 {
  名稱 / 外觀
  需求（目標環境條件）
  等待耐心（可容忍未被滿足的回合數）
  獎勵（從獎勵池隨機抽取：符文 / 卷軸 / 遺物 / 業績加成）
  特殊對話
}
```

#### 需求類型

| 需求類型 | 說明 | 範例 |
|---------|------|------|
| 絕對值條件 | 環境值達到指定數值 | 溫度 >= 8 |
| 相對變化條件 | 自顧客到來後，累積變化量達標 | 顧客來到後水分累積減少 >= 3 |
| 複合條件 | 同時滿足多個條件 | 亮度 >= 6 且 溫度 <= 4 |
| 環境穩定條件 | 條件在連續 1 回合中持續成立（系統追蹤） | 連續 1 回合溫度維持在 4~6 之間 |
| 標籤偏好條件 | 本次送出的卷軸中，指定標籤符文達指定數量 | 卷軸中至少 1 張火系符文 |

> **相對變化條件說明**：計算基準為「顧客到來時的數值」，每回合送出卷軸後累積計算，直到累積變化量達標為止。

#### 顧客範例

| 顧客 | 需求 | 耐心 | 獎勵（隨機池） |
|------|------|------|---------------|
| 落湯雞旅人 | 溫度 >= 8 | 2 回合 | 卷軸或符文（普通～稀有） |
| 感冒農夫 | 顧客來到後水分累積減少 >= 3 | 3 回合 | 符文 ×3（普通） |
| 夜盲商人 | 亮度 >= 10（急客） | 1 回合 | 業績 +20 |
| 冰魔法師 | 溫度 <= 2 且 亮度 >= 5 | 4 回合 | 稀有符文 ×2 |
| 挑剔藥師 | 卷軸中至少 2 張水系符文 且 溫度 <= 5 | 2 回合 | 遺物（可選擇接受） |

#### 顧客獎勵機制

- 顧客獎勵從獎勵池**隨機抽取**，每次出現的獎勵不固定
- 部分顧客可能給予遺物，**玩家可選擇接受或拒絕**
- 顧客憤怒離開時扣除業績，具體數值依顧客類型而定（高耐心顧客扣較少，急客扣較多）

### 3.5 遺物系統

遺物是持續存在的壓力與紅利來源。**遺物只能透過特定符文或卷軸的效果移除**，無法主動捨棄。

#### 遺物結構

```
遺物 {
  名稱
  滿意條件（環境條件）
  標籤偏好（可選，對特定標籤的使用有反應）
  滿意效果（每回合正向效果）
  不滿意效果（每回合副作用）
  不滿意容忍上限（連續不滿意 N 回合後觸發懲罰）
  當前不滿意計數
}
```

#### 不滿意計數規則

- 每回合結算時，若遺物不滿意 → 計數 +1
- 若遺物滿意 → 計數**立刻歸零**
- 計數達到上限後，**觸發懲罰且計數不重置**，後續每回合繼續懲罰，直到遺物再次滿意

#### 遺物取得方式

| 來源 | 說明 |
|------|------|
| 顧客獎勵 | 部分顧客完成後可能給予遺物 |
| 批發商 | 每關通關後可消耗業績購買 |

玩家在取得遺物時**可選擇接受或拒絕**。

#### 多遺物效果順序

玩家可**自由排列遺物順序**（拖曳調整位置），遺物效果從左到右依序結算，後者可覆蓋前者造成的數值。

#### 遺物範例

| 遺物 | 滿意條件 | 標籤偏好效果 | 滿意效果 | 不滿意效果 | 觸發懲罰（達上限） |
|------|---------|------------|---------|-----------|-----------------|
| 日晷 | 亮度 >= 7 | 使用光系符文時業績 +2 | 每回合亮度 +1 | 每回合亮度 -1 | 連續4回合：亮度 -5 |
| 苔蘚石 | 水分 4~8 之間 | 使用水系符文時水分效果 +1 | 每回合業績 +5 | 無額外效果 | 連續3回合：水分強制設為 10 |
| 骸骨燭台 | 溫度 <= 3 | — | 每回合額外抽 1 張符文 | 每回合溫度 +2 | 連續2回合：Game Over |
| 風鈴草 | 三項環境值均在 3~10 | — | 每回合所有正效果 +1 | 下回合隨機一項 -3 | 連續5回合：業績清零 |

#### 遺物設計原則

- 遺物的滿意條件應與顧客需求**有時衝突**，製造策略張力
- 骸骨燭台這類「高風險高報酬」的遺物讓玩家自行評估是否接受
- 持有「驅逐石」或特殊卷軸才能主動移除遺物，賦予遺物管理的策略深度

## 4. 遊戲循環詳解

### 4.1 回合流程

```
┌──────────────────────────────────────────────────┐
│                   回合開始                         │
│                                                  │
│  1. 若無等待顧客 → 新顧客立即到來（顯示需求與耐心）    │
│                    ↓                             │
│  2. 遺物效果結算                                   │
│     ├── 滿意 → 套用滿意效果（亮度+1 等）             │
│     └── 不滿意 → 套用副作用；計數 +1                │
│         └── 計數達上限 → 觸發懲罰（計數不重置）       │
│                    ↓                             │
│  3. 玩家手牌補充（丟棄上回手牌，從牌庫重新抽取）        │
│                    ↓                             │
│  4. 玩家行動：選一個卷軸 → 放滿符文 → 送出            │
│                    ↓                             │
│  5. 環境數值結算（套用卷軸效果，觸發極端事件檢查）       │
│                    ↓                             │
│  6. 顧客需求判定                                   │
│     ├── 滿足 → 隨機給予獎勵，業績 +N，顧客離開        │
│     │         └── 顧客離開 → 立刻迎接下一位          │
│     └── 未滿足 → 顧客耐心 -1                       │
│                    ↓                             │
│  7. 顧客耐心判定                                   │
│     ├── 耐心 > 0 → 等待下一回合                     │
│     └── 耐心 = 0 → 顧客憤怒離開，業績 -N             │
│                    ↓                             │
│  8. 遺物不滿意計數更新（若此回合已在步驟2更新則跳過）    │
│                    ↓                             │
│         回合結束，進入下一回合                        │
└──────────────────────────────────────────────────┘
```

### 4.2 通關與批發商

```
顧客隊列清空
      ↓
   關卡通關
      ↓
  進入批發商
  （消耗業績購買符文 / 卷軸 / 遺物）
      ↓
  進入下一關（難度提升）
```

## 5. 玩家資源管理

### 5.1 手牌系統

- 每回合開始，**丟棄上回所有手牌**，從牌庫重新抽取（無手牌上限）
- 牌庫抽完後洗牌，循環型符文回到牌庫；消耗型符文永久移除
- 顧客或批發商給予的符文直接加入牌庫

### 5.2 卷軸管理

- 卷軸為**消耗品**，送出後永久移除
- 補充來源：顧客獎勵（隨機）、批發商（花業績購買）
- 沒有卷軸可用時玩家無法行動，須設法透過顧客獎勵取得

### 5.3 牌庫構築

- 初始牌庫包含基本款循環型符文（水珠 ×3、小燭 ×3、蒸氣 ×2）
- 初始卷軸為基本卷軸 ×3
- 遺物不在初始配置中，遊戲途中透過顧客或批發商取得
- 可在批發商處移除不需要的符文（減少雜訊，花少量業績）

---

## 6. 批發商系統

批發商在每關通關後出現，玩家可消耗業績強化自己的牌池。

### 6.1 批發商商品

| 商品類型 | 說明 | 業績成本（草案） |
|---------|------|---------------|
| 普通符文 | 從普通池隨機顯示 3 張，選 1 | 5 |
| 稀有符文 | 從稀有池隨機顯示 2 張，選 1 | 15 |
| 傳說符文 | 從傳說池隨機顯示 1 張 | 35 |
| 基礎卷軸 | 固定商品 | 8 |
| 進階卷軸 | 隨機顯示 2 種，選 1 | 20 |
| 遺物 | 隨機顯示 2 個，可選擇接受或拒絕 | 25 |
| 移除符文 | 從牌庫移除一張指定符文 | 10 |

### 6.2 批發商設計原則

- 業績同時是成績指標與購買貨幣，每次消費都是取捨
- 商品隨機展示，不能重複刷新（避免完美最佳化路線）

---

## 7. 勝負判定

### 7.1 失敗條件

- 業績降至 **0**（Game Over）
- 遺物觸發「即死」懲罰（如骸骨燭台上限）

### 7.2 通關條件

- 清空當關所有顧客隊列 → 進入批發商 → 進入下一關
- 遊戲無終點，關卡難度持續遞增，以業績衡量玩家最終成績

---

## 8. 進程與隨機性

### 8.1 Roguelite 元素

| 元素 | 說明 |
|------|------|
| 隨機符文獎勵 | 顧客給予的符文從池中依稀有度機率隨機抽取 |
| 隨機顧客隊列 | 每局顧客順序不同，部分特殊顧客以機率出現 |
| 隨機批發商商品 | 每次通關後批發商展示隨機商品 |
| 隨機事件 | 特定回合可能出現「環境異變」事件，大幅改變環境數值 |

### 8.2 難度曲線

- **早期**：需求簡單（單一條件、寬鬆範圍），無遺物壓力
- **中期**：出現複合條件顧客、第一個遺物、標籤偏好需求
- **後期**：顧客耐心縮短，遺物不滿意上限降低，隊列更長

### 8.3 全卡開放

所有符文、卷軸、遺物從遊戲開始就加入獎勵池，無需解鎖。深度來自組合的可能性，而非內容的逐步解鎖。

## 9. UI / UX 草案

### 9.1 主遊戲畫面配置

```

│  亮度: 7  水分: 5  溫度: 3   [業績: 120]     │
├─────────────────┬──────────────────────────┤
│  [遺物區]        │  [顧客區]                 │
│  日晷  ✓ (0/4)  │  落湯雞旅人               │
│  苔蘚石 ✗ (2/3) │  需求: 溫度 >= 8           │
│  ← → 調整順序   │  耐心: ██░ (1回合剩餘)      │
├─────────────────┴──────────────────────────┤
│  [卷軸工作台]                               │
│  [基礎卷軸 ▼]  槽位: [水珠][小燭]  → [送出]  │
│  預覽: 水分+2  亮度+1  溫度+1               │
├────────────────────────────────────────────┤
│  [手牌區]                                   │
│  [水珠][小燭][寒冰][黑霧][蒸氣][水珠][小燭]   │
└────────────────────────────────────────────┘
```

### 9.2 互動流程

1. 點擊卷軸下拉選單，預覽各卷軸的槽數、規則、標籤限制
2. 從手牌拖曳（或點選）符文放入槽位
3. 卷軸即時預覽最終環境 delta（亮度+1、水分+2...）及標籤連鎖加成提示
4. 點擊「送出」，播放效果動畫，環境數值更新，顧客進行需求判定
5. 遺物區顯示每個遺物的滿意狀態（✓/✗）與不滿意計數進度條
6. 穩定條件類顧客需求顯示追蹤進度（如「連續1回合：0/1」）

## 11. 設計哲學與注意事項

1. **強迫取捨**：卷軸必須放滿，每次送出都有副作用，不存在完美解
2. **多目標競爭**：顧客需求 vs 遺物條件 vs 環境極端事件，三方壓力讓每回合都有決策空間
3. **業績是資源也是生命**：消費業績強化牌池 vs 保留業績避免 Game Over，貫穿全局的核心張力
4. **可預測性**：環境數值與遺物狀態完全透明，失敗來自決策失誤而非資訊不足
5. **標籤帶來組合深度**：標籤系統讓牌庫構築有明確的「方向感」，顧客偏好與遺物觸發強化特定策略路線
6. **短局設計**：單局時間控制在 20~35 分鐘，適合反覆遊玩
