### 1.4 `OpenScrollUI.cs` — 捲軸展開/收合

```csharp
// SetNotEmpty() — 展開內容
notEmptyView.transform.DOKill();
notEmptyView.SetActive(true);
notEmptyView.transform.DOScale(1f, 0.2f).From(0.85f).SetEase(Ease.OutBack);

// SetEmpty() — 收合內容
notEmptyView.transform.DOKill();
notEmptyView.transform.DOScale(0.85f, 0.15f)
    .SetEase(Ease.InBack)
    .OnComplete(() => notEmptyView.SetActive(false));
```

**效果：** 選擇捲軸時內容區域彈出，取消選擇時縮回。

## 優先級 2 — 顧客進場/離場

**檔案：** `CustomerUI.cs`
**時機：** 顧客物件生成 / 銷毀時

### 進場（Apply() 後呼叫）

```csharp
// 整個顧客 UI Panel 從右側滑入 + 淡入
CanvasGroup cg = GetComponent<CanvasGroup>() ?? gameObject.AddComponent<CanvasGroup>();
cg.alpha = 0f;
cg.DOFade(1f, 0.35f).SetEase(Ease.OutQuad);
transform.DOLocalMoveX(transform.localPosition.x, 0.35f)
         .From(transform.localPosition.x + 80f)
         .SetEase(Ease.OutCubic);
```

### 離場（在 Destroy 前呼叫，完成後再 Destroy）

```csharp
CanvasGroup cg = GetComponent<CanvasGroup>();
cg.DOFade(0f, 0.25f).SetEase(Ease.InQuad)
  .OnComplete(() => Destroy(gameObject));
transform.DOLocalMoveX(transform.localPosition.x - 80f, 0.25f)
         .SetEase(Ease.InCubic);
```

## 優先級 6 — 環境數值更新（Counter 動畫）

**檔案：** `UpdateBrightness.cs`、`UpdateTemperature.cs`、`UpdateMoisture.cs`、`UpdateRevenue.cs`

每個腳本的 `SetText()` 方法改為數字滾動：

```csharp
// 以 UpdateRevenue 為例，其他同理（需要儲存前一個值）
private int _currentDisplayValue;

public void SetText(int newValue)
{
    DOTween.To(
        () => _currentDisplayValue,
        x => { _currentDisplayValue = x; _text.text = x.ToString(); },
        newValue,
        0.4f
    ).SetEase(Ease.OutQuad);
}
```

數值跳動時可加入顏色閃爍：
```csharp
_text.DOColor(Color.yellow, 0.1f).OnComplete(() => _text.DOColor(Color.white, 0.2f));
```

## 通用規範

1. **永遠在新 tween 前呼叫 `DOKill()`**，防止動畫疊加衝突。
2. **使用 `SetEase(Ease.OutBack)`** 進場（有彈性感），**`Ease.InBack`** 離場（收縮感）。
3. **SetActive(false) 必須在 OnComplete callback** 中執行，不可在 tween 前執行。
4. **時間控制原則：** 互動回饋 ≤ 0.15s，面板開關 0.2–0.3s，進退場 0.3–0.5s，特殊強調 ≤ 0.6s。
5. **CanvasGroup** 用於整體淡入淡出；**DOScale** 用於縮放；**DOPunchScale / DOShakePosition** 用於一次性強調。
