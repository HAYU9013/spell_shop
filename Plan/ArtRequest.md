# Spell Shop — 美術素材需求清單

---

## 1. 符文卡牌

每張符文需要：**卡牌圖示**（主視覺）、**卡面框架**（依稀有度區分）

### 1.1 卡面框架（3 種）

| 稀有度 | 說明                     |
| ------ | ------------------------ |
| 普通   | 樸素邊框，灰/棕色調     |
| 稀有   | 精緻邊框，發光紋路       |
| 傳說   | 華麗邊框，金色 + 粒子感  |

### 1.2 符文類型標記（2 種）

| 類型   | 標記說明                          |
| ------ | --------------------------------- |
| 循環型 | 卡牌角落的循環箭頭圖示（可重複使用） |
| 消耗型 | 卡牌角落的火焰/碎裂圖示（一次性）   |

### 1.3 標籤圖示（6 種）

顯示在卡牌上方或角落，標示符文所屬標籤。

| 標籤   | 圖示意象             | 色調     |
| ------ | -------------------- | -------- |
| 水系   | 水滴                 | 藍色     |
| 火系   | 火焰                 | 紅/橘色  |
| 光系   | 太陽/光芒            | 黃/金色  |
| 暗系   | 月亮/陰影            | 紫/深藍  |
| 風系   | 旋風/氣流            | 青/淺綠  |
| 中性   | 平衡石/圓環          | 灰/白色  |

### 1.4 符文圖示（目前已知 7 種，最終 25+ 種）

**Phase 1 基礎符文（8 種）**

| 符文名稱 | 圖示意象                   | 標籤       | 稀有度 |
| -------- | -------------------------- | ---------- | ------ |
| 水珠     | 一顆發光的藍色水珠         | 水系       | 普通   |
| 小燭     | 一根燃燒的蠟燭             | 火系、光系 | 普通   |
| 寒冰     | 尖銳的冰晶                 | 水系       | 稀有   |
| 太陽核   | 燃燒的太陽碎片             | 火系、光系 | 傳說   |
| 黑霧     | 飄散的黑色霧氣             | 暗系       | 普通   |
| 蒸氣     | 升騰的白色蒸汽             | 中性       | 普通   |
| 驅逐石   | 帶有驅散紋路的灰色石頭     | 中性       | 稀有   |
| （待定） | Phase 1 第 8 張，待設計    | —          | —      |

**Phase 4 擴充符文（額外 17+ 種，待企劃確定後補充）**

| 符文名稱 | 圖示意象                   | 標籤   |
| -------- | -------------------------- | ------ |
| 熔岩珠   | 岩漿球體                   | 火系   |
| 螢石     | 發光的螢光礦石             | 光系   |
| 陰影核   | 凝聚的暗影球體             | 暗系   |
| 微風     | 輕柔的風線條               | 風系   |
| 颶風珠   | 強烈旋轉的風球             | 風系   |
| 平衡石   | 完美對稱的天然石頭         | 中性   |
| ...      | （其餘待設計）             | —      |

## 2. 卷軸

每種卷軸需要：**卷軸圖示**（庫存列表用）、**工作台展開外觀**（放符文時的展開視覺）

### 2.1 卷軸圖示（目前 6 種，最終 12+ 種）

| 卷軸名稱 | 圖示意象                             | 槽數 |
| -------- | ------------------------------------ | ---- |
| 基礎卷軸 | 樸素的米色卷軸                       | 2    |
| 放大卷軸 | 帶有放大鏡符號的卷軸                 | 3    |
| 純化卷軸 | 白色發光的潔淨卷軸                   | 2    |
| 水系卷軸 | 藍色波紋裝飾的卷軸                   | 3    |
| 平衡卷軸 | 天秤圖案的卷軸                       | 4    |
| 逆轉卷軸 | 陰陽/反轉箭頭的卷軸                  | 2    |

### 2.2 卷軸工作台元件

| 元件             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 卷軸展開背景     | 卷軸攤開後的底圖，上方有空槽位                 |
| 符文槽位（空）   | 空的符文放置格（虛線方框）                     |
| 符文槽位（已放入）| 放入符文後的高亮邊框                           |
| 標籤限制提示     | 卷軸展開時顯示「僅限水系」等限制的裝飾圖示     |
| 送出按鈕         | 「送出」按鈕（正常/禁用/懸停三態）             |

## 5. 環境系統 UI

### 5.1 環境數值面板

| 元件             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 亮度圖示         | 太陽圖示，數值越高越亮                         |
| 水分圖示         | 水滴圖示，數值越高越飽滿                       |

| 事件       | 視覺效果                                     |

## 9. 動畫與特效

### 9.1 卡牌動畫

| 動畫             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 抽牌動畫         | 符文從牌庫飛入手牌區                           |
| 棄牌動畫         | 手牌全部飛向棄牌堆                             |
| 放入槽位動畫     | 符文從手牌滑入卷軸槽位                         |
| 移出槽位動畫     | 符文從槽位回到手牌                             |
| 消耗型碎裂動畫   | 消耗型符文使用後碎裂消散                       |
| 卷軸消耗動畫     | 卷軸送出後燃燒/消散                            |

### 9.2 環境變化動畫

| 動畫             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 數值增加         | 進度條增長 + 綠色飄字 +N                       |
| 數值減少         | 進度條縮短 + 紅色飄字 -N                       |
| 業績增加         | 金幣飛入 + 數字跳動                            |
| 業績減少         | 紅色閃爍 + 數字下降                            |

### 9.3 顧客動畫

| 動畫             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 顧客登場         | 從右側走入/淡入                                |
| 顧客滿足離開     | 開心表情 + 向右走出                            |
| 顧客憤怒離開     | 生氣表情 + 快速衝出/消散                       |
| 耐心減少         | 耐心條閃爍縮短                                 |

### 9.4 遺物動畫

| 動畫             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 滿意觸發         | 綠色光圈脈動                                   |
| 不滿意觸發       | 紅色邊框閃爍                                   |
| 懲罰觸發         | 震動 + 裂紋擴散 + 衝擊波                       |
| 遺物取得         | 遺物圖示飛入遺物區                             |
| 遺物移除         | 遺物碎裂消散（驅逐石效果）                     |
| 排序拖曳         | 遺物圖示跟隨手指/滑鼠移動                      |

### 9.5 回合轉場

| 動畫             | 說明                                           |
| ---------------- | ---------------------------------------------- |
| 回合開始         | 輕微的場景亮起/「第 N 回合」文字閃現           |
| 關卡通關         | 「通關！」文字 + 場景過渡到批發商               |
| Game Over        | 畫面變暗 + 「Game Over」文字漸入               |

## 12. 風格參考

| 項目       | 方向                                           |
| ---------- | ---------------------------------------------- |
| 整體風格   | 奇幻手繪風，溫暖但帶有神秘感                   |
