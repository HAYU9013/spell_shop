# Spell Shop — 功能盤點
> 日期：2026-03-21

## 已完成 ✅

### 核心架構
- [x] **GameDefinitions.cs** — 全域 enum / struct 定義（EnvAttribute、RuneTag、ScrollModifierType 等）
- [x] **GameFacade.cs** — UI 統一入口，所有讀寫 API 與事件廣播
- [x] **GameFacadeSnapshots.cs** — UI 用 snapshot 資料結構（WorkbenchSnapshot、CustomerSnapshot、RelicSnapshot）
- [x] **TurnManager.cs** — 8 Phase 狀態機（Enter / Execute / Exit 生命週期）

### Turn States（8 個全部完成）
- [x] CustomerArrivalState — 召喚下一位客人 / 觸發關卡結束
- [x] RelicTriggerState — RelicManager.TickAll()
- [x] DrawCardsState — 棄手牌、補牌
- [x] PlayerActionState — 等待玩家送出（waiting flag）
- [x] EnvironmentResolveState — 套用卷軸效果、更新追蹤、記錄快照
- [x] CustomerJudgeState — 判斷需求是否滿足
- [x] PatienceCheckState — 扣耐心、處理離場
- [x] RelicUpdateState — 遊戲結束條件、OnTurnEnd

### 環境系統
- [x] **EnvironmentData.cs** — 亮度 / 水分 / 溫度（0–20）+ 業績
- [x] **EnvironmentManager.cs** — Singleton、ApplyEffects、ForceSetValue、歷史快照（deque）、極端事件連鎖
- [x] **ExtremeEventHandler.cs** — 黑暗降臨 / 大洪水（+5水分）/ 過熱 / 嚴寒（各扣10業績）

### 顧客系統
- [x] **CustomerData.cs** — ScriptableObject（名字、立繪、需求、耐心、獎勵）
- [x] **CustomerInstance.cs** — Runtime 包裝（耐心追蹤、UpdateTracking、CheckRequirements、TickPatience）
- [x] **CustomerManager.cs** — Queue + Endless Pool、召喚/離場/耐心事件
- [x] **IRequirement.cs** — 需求介面
- [x] **RequirementFactory.cs** — 依 RequirementData 建立對應 IRequirement
- [x] **AbsoluteRequirement.cs** — 當前數值比較（>=, <=, ==, InRange）
- [x] **RelativeChangeRequirement.cs** — 相對變化量（累積 delta）
- [x] **StabilityRequirement.cs** — 連續回合維持條件

### 符文系統
- [x] **RuneData.cs** — ScriptableObject（名字、稀有度、標籤、效果陣列、discardOtherRunes）
- [x] **RuneInstance.cs** — IsExhausted 追蹤（Cycle / Consumable 行為差異）
- [x] **DeckManager.cs** — 初始化、抽牌、棄牌、洗牌（Fisher-Yates）、AddRune（獎勵）

### 卷軸系統
- [x] **ScrollData.cs** — ScriptableObject（名字、slotCount、修飾類型、multiplier、tagFilter）
- [x] **ScrollInstance.cs** — InstanceId 包裝
- [x] **ScrollInventory.cs** — 卷軸庫存（Init / AddScroll / DiscardScroll）
- [x] **ScrollProcessor.cs** — 6 種修飾類型計算（DirectAdd / MultiplyAll / PositiveOnly / TagMultiply / Average / Invert）
- [x] **SubmitRecord.cs** — 記錄本次送出的卷軸 + 符文

### 遺物系統
- [x] **RelicData.cs** — ScriptableObject（條件、滿足/不滿足效果、懲罰類型）
- [x] **RelicInstance.cs** — UnsatisfiedCount、Tick、ForceIncrementUnsatisfied
- [x] **RelicManager.cs** — InitRelics、TickAll、ApplyPunishment（EnvironmentShock / ScoreReset / PlayerDeath）

### 獎勵系統
- [x] **RewardEntry.cs** — 可序列化的獎勵設定（Score / Rune / Scroll / Relic）
- [x] **RewardManager.cs** — Grant（Score、Rune、Scroll 三種已實作）、OnRewardGranted 事件

### Workbench 系統
- [x] **WorkbenchManager.cs** — SelectScroll、PlaceRune、RemoveRune、CanSubmit、Submit（處理 Cycle/Consumable/DiscardEffect）

### GameManager
- [x] 所有子系統初始化順序
- [x] Level / Endless 模式
- [x] Game Over（業績歸零 / 遺物即死懲罰）
- [x] Level Clear（Queue 清空）

### UI — 已完成
- [x] **UpdateBrightness / Moisture / Temperature / Revenue** — 訂閱事件、即時更新 TextMeshProUGUI
- [x] **CustomerUI.cs** — 顯示客人名字、flavorText、立繪；顧客到來/離場生命週期

- [x] **RuneCardUI.cs** — 選取/取消選取視覺（scale）、HandSelectionState 整合
- [x] **HandSelectionState.cs** — 靜態選取狀態（SelectedIndex / SelectedRuneData / OnSelectionChanged）
- [x] **ScrollsPileUI.cs** — 列出所有可用卷軸、縱向排列
- [x] **ScrollCardUI.cs** — 點擊選取卷軸、高亮切換
- [x] **OpenScrollUI.cs** — 空/非空視圖切換、槽位動態 Rebuild、顯示卷軸名稱與效果
- [x] **SlotUI.cs** — 空槽/已填槽視圖切換、點擊放置/移除符文
- [x] **DeckUI.cs** — Submit 按鈕啟用/禁用（CanSubmit）
- [x] **OpenDeskUI.cs** — Toggle DeskUI 面板 active 狀態
- [x] **FinalResult.cs** — OnLevelClear（You Win）/ OnGameOver（You Die）面板
